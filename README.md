# courses.dybka.ru

Авторские курсы без использования нейросетей и встроеных платежей. Игры на Unity, сайты, мобильная разработка. Все бесплатно с открытым кодом и без регистрации.

[Смотреть курсы](https://courses.dybka.ru/)

## Запуск

Нужен [Node.js](https://nodejs.org/).

```bash
cd app
npm install
npm start
```

Сайт откроется на адресе, который покажет Vite (обычно http://localhost:5173).

Сборка для продакшена:

```bash
npm run build
```
